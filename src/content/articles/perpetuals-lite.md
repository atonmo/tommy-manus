## Background · 项目背景

2026 Q2 全球BX用户调研显示，68.4% 的活跃用户使用过合约，41.2% 将其视为选择BX的首要原因；同时，81.3% 的用户主要通过移动端完成交易。这说明合约是BX平台的核心护城河，尤其是移动端的交易体验直接关系到用户满意度和忠诚度。

[[stats:72|NPS 净推荐值 ;; 4.3|整体满意度（5 分制）;; 68%|合约功能使用率 ;; 81%|移动端为主交易入口]]

报告中还发现相比全球其他地区，拉美地区（巴西，墨西哥）用户增长最快。所以给我们的命题是如何能吸引拉美地区用户，留住用户并持续增长。用户并不缺少合约交易意愿，但大量需求仍停留在「跟随别人交易」：当用户尝试独立开仓时，专业合约页同时呈现盘口、杠杆、保证金与强平等专业信息，在有限的移动端空间里形成明显的认知和操作门槛。

要把已有的跟单用户与高意向新手进一步转化为自主交易用户，就不能只优化专业版的局部体验，而需要尽快建立一套更易理解、更短链路、体验顺畅的合约轻量版，让用户从「愿意参与」真正走到「看得懂、敢下单、会管理」。

![从意愿用户到自主用户的转变](/articles/perpetuals-lite/07-user-shift.png "Shift · Willing → Independent")

## Design Context · 设计目标

## 01· 问题现状

我们组织了一次团队内部的专家走查，大家一致认为现有专业版默认服务对象是熟练交易者，是把理解成本全部推给用户，对于一名只是对合约略有所知的新手用户是十分不友好的。按开仓前->开仓中->开仓后的路径大致总结了如下几个问题：

[[problem-cards]]

- **信息密度高**{开仓前}专业概念在首屏集中出现，多 / 空、杠杆、保证金与强平同时要求理解；新手用户尚未建立基础认知，就被迫做出高风险决策。
- **开仓路径长**{开仓中}下单链路被参数与层级切碎，金额、杠杆、止盈止损分散在多个面板；移动端反复填写和确认，让第一次开仓变得冗长且容易中断。
- **仓位管理复杂**{开仓后}多仓位混合在一起，降低了用户对仓位的把控力，同时也带来了仓位风险反馈晚，造成用户「不敢下单」。

## 02· 数据洞察

我们拉取了专业版合约交易页近 30 天的功能埋点，数据说明了几个判断：用户把大量点击花在「看」和「试」上，真正构成风险防线的功能几乎无人触达。


| 核心功能                  | 点击率 | 行为解读                         |
| --------------------- | --- | ---------------------------- |
| K 线图表 · 周期切换          | 87% | 使用频率最高，但多为反复缩放观望，「看得多、下不了手」  |
| 开多 / 开空（Long / Short） | 64% | 点击高、成交低，近三成停在方向选择后退出，术语语义不直观 |
| 杠杆调节                  | 52% | 集中在默认档反复试探，用户不理解倍数与强平价的关系    |
| 委托类型切换（市价 / 限价）       | 31% | 大部分用户全程只用市价，限价、计划委托形同虚设      |
| 保证金模式切换               | 18% | 全仓 / 逐仓概念模糊，多数用户从未主动切换       |
| 止盈止损设置                | 12% | 最关键的风险工具触达率最低，亏损后才被动了解       |
| 滑点设置                  | 10% | 概念过于专业，默认值一用到底；成交价偏离预期时才追问「为什么亏了」 |
| 仓位列表 · 平仓管理           | 9%  | 多仓位混排看不懂持仓状态，平仓入口深、操作滞后      |



## 03· 设计目标

### Target 01 · 用户 · 操作不再是阻碍收益的门槛

决策链路短、术语有解释、误触成本低，让小白先完成一次看得懂的开仓。

### Target 02 · 设计 · 符合拉美小白操作习惯

大触控、直观 Long / Short 语义、本地化表达节奏，降低移动端认知负担。

### Target 03 · 业务 · 提升该人群使用量

把「看懂 → 敢下 → 会管风险」串成可完成路径，把潜在用户引进交易池。

## 01.A · 重建首交链路 · 看趋势 → 选方向 → 滑一下

主界面丢掉盘口深度与复杂委托，只保留涨跌概况、可读走势与 Long / Short。
下单页用量化和百分比快选降低输入摩擦，并用滑动确认兼顾防误触与效率。

#### 方向优先于参数

先选涨跌，再填成本与杠杆，符合小白决策顺序。

#### 成本即输入单位

按可用余额输入并实时换算仓位价值，保证金概念后置。

#### 滑动二次确认

把提交做成有成本的手势，降低单点误触。

极简下单链路

## 01.B · 风险管理可视化 · 而不是藏进高级设置

TP/SL 与杠杆做成可教学的独立半屏：图表拖拽设止盈止损，杠杆支持滑动与精确输入，
仓位卡优先展示未实现盈亏与预估强平价，并把出场收敛为一键动作。

- **图表拖拽 TP/SL**：价格线与百分比同步反馈
- **杠杆双通道**：直觉滑动 + 数字精确输入
- **术语旁路解释**：关键参数保留 "What is …？" 入口

止盈止损、杠杆与持仓管理

## 02.A · 新手引导 · 用会动的视频完成概念补课

首交前补齐开多、开空、杠杆、强平四块认知。引导全部动态视频呈现，
视觉叙事统一为「收益如何随价格变化」。教学素材由 AI 批量生成并人工校准，
把制作周期从周压缩到日。


| 步骤  | 概念  | 叙事                  |
| --- | --- | ------------------- |
| 01  | 开多  | 预期上涨 → 买入 → 上涨获利    |
| 02  | 开空  | 预期下跌 → 卖出 → 下跌获利    |
| 03  | 杠杆  | 较少保证金撬动更大仓位         |
| 04  | 强平  | 保证金不足时强制平仓，可能损失全部本金 |

## Visual · 视觉原则

#### 深色交易语境

降低噪声，让涨跌色成为唯一强对比。

#### 大触控 · 少层级

核心决策占拇指热区，减少页内跳转。

#### 术语可读化

必要专业词保留，配套即时解释，不靠近义词掩盖复杂度。

## Design Reflection · 把复杂产品里的第一条成功路径单独产品化 · → 先完成，再接通完整能力

轻量版不是把永续交易「做得更简单看」，而是让用户先完成一次看得懂、下得去、管得住的交易，
再逐步接回完整合约能力。人群切口决定产品形态，风险教育要嵌进任务，AI 服务交付节奏而非替代理解。

### 01 · 人群切口决定产品形态

面向拉美小白，就必须重排信息架构，而不是在主面板继续堆引导。

### 02 · 风险教育嵌进任务

TP/SL、杠杆、强平只有出现在决策现场时才真正有效。

### 03 · AI 服务交付节奏

用在教学动效与并发探索，不替代对交易路径的判断。
